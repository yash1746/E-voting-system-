National E-Voting System — Project SynopsisSection 1 & 2
1. Abstract

The National E-Voting System is a full-stack web application designed to conduct government-grade digital elections in a secure, anonymous, and transparent manner. The system addresses major challenges of traditional voting: physical inaccessibility, risk of ballot manipulation, identity fraud, and lack of transparency in the counting process.

Using modern cryptographic techniques — AES-256-GCM encryption and SHA-256 hash chains — the platform guarantees that every ballot is anonymous, every vote is immutable after casting, and the entire election record can be verified publicly by any citizen. Multi-step government ID verification ensures only registered voters participate, while a dedicated administrative panel gives election officers full control over the election lifecycle.

2. Introduction & Problem Statement

2.1 Background

Traditional paper-based voting systems suffer from multiple challenges including logistical limitations, physical ballot tampering, counting errors, and accessibility issues for remote or physically challenged voters. Earlier electronic voting machines (EVMs) addressed some concerns but lacked public transparency and remote accessibility.

With increasing internet penetration and digital literacy, an internet-based voting system that combines strong security with ease of access is both practical and necessary.

2.2 Problem Statement

Design and implement a web-based e-voting system that:

  • Allows only verified, registered voters to cast votes using government-issued identity verification
  • Guarantees complete voter anonymity — no link between a voter's identity and their ballot
  • Prevents duplicate voting even if a voter attempts to cast multiple times
  • Makes the voting record tamper-proof using cryptographic techniques
  • Provides a publicly accessible audit trail for election transparency
  • Gives citizens access to party manifestos, actions, and speeches before voting
Core Challenge: How do you simultaneously guarantee that a vote is authentic (came from a real, eligible voter), anonymous (cannot be traced back to the voter), and immutable (cannot be changed after submission)?

3. Objectives of the Project
  1. Implement a 3-step government-style authentication (Voter ID → OTP → Session) to verify voter identity
  2. Achieve complete ballot anonymity through database design that physically separates voter identity from vote content
  3. Prevent dual voting using database-level unique constraints at the (voter, election) pair
  4. Implement SHA-256 hash chaining to create a tamper-evident, immutable vote ledger
  5. Provide a public audit trail where any citizen can verify chain integrity and their own vote receipt
  6. Build a Party Transparency Portal showcasing each party's actions, legislation record, and speeches
  7. Develop a full Admin Panel for managing elections, voter registry, and audit logs
  8. Apply industry-standard security middleware stack (Helmet, CORS, rate limiting, CSP)
4. System Architecture

4.1 Three-Tier Architecture

The system follows a classic three-tier model: a static frontend, a Node.js/Express API server, and a Supabase (PostgreSQL) managed database. The frontend communicates with the server exclusively through a REST API with session cookies.

4.2 Database Design

The database contains 9 tables. The most critical design decision is the separation of identity and ballot into two tables:

  • votes — stores encrypted ballot + hash chain. Contains NO voter reference whatsoever.
  • vote_receipts — stores only that a voter voted in an election, NOT what they voted for.

5. Authentication Flow

Instead of traditional username/password or OAuth login, the system uses a Government-ID-based OTP verification in 3 steps. This mimics real electoral card verification and provides two-factor security.

Figure 3: 3-Step Authentication Sequence

7. Security Mechanisms

7.1 SHA-256 Hash Chain

The system implements a blockchain-inspired hash chain for all votes. Each vote contains a hash of itself and a link to the hash of the previous vote. This creates a chain where tampering with any single record breaks all subsequent links.

Figure 5: SHA-256 Hash Chain for Tamper-Evidence
graph LR G["🔰 Genesis\nprev_hash = 00000000"] V1["Vote #1\nvote_hash = H₁\nprev_hash = 00000000"] V2["Vote #2\nvote_hash = H₂\nprev_hash = H₁"] V3["Vote #3\nvote_hash = H₃\nprev_hash = H₂"] VN["...Vote #N\nprev_hash = Hₙ₋₁"] FORMULA["vote_hash = SHA256(encrypted_ballot)\nprev_hash = vote_hash of previous vote"] G ==>|links to| V1 ==>|links to| V2 ==>|links to| V3 ==>|links to| VN style G fill:#dbeafe,color:#1e3a8a,stroke:#1d4ed8 style V1 fill:#eff6ff,color:#1e3a8a,stroke:#93c5fd style V2 fill:#eff6ff,color:#1e3a8a,stroke:#93c5fd style V3 fill:#eff6ff,color:#1e3a8a,stroke:#93c5fd style VN fill:#eff6ff,color:#1e3a8a,stroke:#93c5fd style FORMULA fill:#fafafa,color:#333,stroke:#ccc
If Vote #2 is tampered with, H₂ changes → Vote #3's prev_hash validation fails → entire chain from #3 onwards is flagged as broken.
Audit Trail: Any citizen can visit the Audit page and verify: (1) the entire chain is intact, (2) their specific vote receipt is included in the chain. This provides full public transparency without revealing who voted for whom.

10. Conclusion

The National E-Voting System successfully addresses all core challenges of digital voting through a combination of careful database design, cryptographic security, and transparent audit mechanisms. The system demonstrates that it is possible to conduct elections that are simultaneously authenticated (only real voters can vote), anonymous (the ballot cannot be traced to the voter), and transparent (anyone can verify the chain of all votes).

The project is production-ready with a modular backend, a premium UI, and a complete admin workflow. Future enhancements could include biometric verification integration, blockchain-based distributed audit nodes, and mobile application support.

Key Achievement: The system solves the fundamental paradox of democratic voting — ensuring every vote is authentic and counted, while guaranteeing that no one can ever determine how any individual voted.
